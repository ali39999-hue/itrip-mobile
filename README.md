# iTrip Mobile (Firuzo) · گاوصندوق دیجیتال و همراه هوشمند سفر

> **همراه عملیاتی سفر و گاوصندوق دیجیتال گردشگران پلتفرم فیروزو (iTrip) برای سیستم‌عامل اندروید**  
> مبتنی بر React Native 0.77+، پایدار بر بستر Expo SDK 52 (New Architecture) و سیستم طراحی NativeWind v4.

---

## 🌟 ویژگی‌های کلیدی (Key Pillars)

1. **گاوصندوق آفلاین سفر (Offline-First Travel Vault):**
   - دسترسی دائمی و بدون نیاز به اینترنت به بلیت‌های پرواز، کدهای QR و ووچرهای اقامتی.
   - **کارت آدرس هتل برای رانندگان تاکسی (Driver Card):** نمایش مشخصات و آدرس هتل به خط فارسی به رانندگان بدون نیاز به ارتباط داده.
2. **یکپارچگی عمیق مالی با NewCash:**
   - نمایش موجودی ارزی (USD/EUR) و تبدیل ریالی با نرخ زنده.
   - تضمین عدم رخداد خطاهای ممیز شناور پولی با موتور محاسباتی `decimal.js`.
   - کارت‌های بانکی توریستی فیزیکی قابل اتصال به کلیه پایانه‌های فروشگاهی و خودپردازهای شبکه شتاب.
3. **پشتیبانی کامل ۵ زبانه و چیدمان دوجهته (Bidirectional i18n):**
   - زبان‌های راست‌به‌چپ (فارسی `fa`، عربی `ar`) و چپ‌به‌راست (انگلیسی `en`، چینی `zh`، روسی `ru`).
   - حفظ جهت استاندارد داده‌های پرواز و مبالغ در تمام زبان‌ها.
4. **امنیت سخت‌افزاری و ذخیره‌سازی محافظت‌شده:**
   - ذخیره‌سازی توکن‌های نشست در Android Keystore از طریق `SecureStore`.
   - آمادگی برای ورود بیومتریک (اثر انگشت و تشخیص چهره).

## 🛠 استک فناوری (Technology Stack)

| لایه / ماژول | فناوری / کتابخانه |
| :--- | :--- |
| **فریم‌ورک پایه** | React Native 0.77 + Expo SDK 52 (Fabric / TurboModules / Hermes) |
| **مسیریابی** | Expo Router v4 (File-based Tabs & Stacks) |
| **دیزاین سیستم** | NativeWind v4 + Tailwind CSS (انطباق ۱:۱ با توکن‌های فیروزو) |
| **مدیریت استیت** | Zustand v5 + TanStack Query v5 |
| **موتور محاسبات مالی** | Decimal.js (Fixed-point Money Arithmetic) |
| **چندزبانی** | i18next + react-i18next (5 Locales) |
| **تست‌های واحد** | Vitest 2.1 |

## 📁 ساختار پوشه‌بندی (Directory Structure)

```text
src/
├── app/                  # مسیریابی مبتنی بر فایل (Expo Router)
│   ├── (auth)/           # ورود، ارسال و بررسی OTP
│   ├── (tabs)/           # تب‌های پنج‌گانه اصلی (خانه، جستجو، سفرها، کیف‌پول، حساب)
│   └── _layout.tsx       # ریشه ناوبری و بازیابی نشست (Bootstrap)
├── components/
│   ├── shared/           # بنر آفلاین و صفحات نگهدارنده
│   └── ui/               # Button, Input, Card, Badge, OfflineBanner, TabIcons
├── domains/              # هسته دامنه خالص (Pure TypeScript)
│   ├── booking/          # ماشین وضعیت رزرو و تست‌های انتقال
│   ├── currency/         # موتور تبدیل و محاسبات پولی (Money Engine)
│   └── identity/         # اعتبارسنجی گذرنامه و مسافران با Zod
├── hooks/                # هوک‌های وضعیت شبکه و احراز هویت
├── i18n/                 # ترجمه‌ها و تنظیمات چندزبانی (fa, ar, en, zh, ru)
├── services/             # کلاینت HTTP آکسیوس، اینترسپتورها و SecureStore
├── stores/               # استور نشست کاربری (authStore)
└── styles/               # توکن‌های رنگی فیروزو و global.css
```

## 🚀 راه‌اندازی و توسعه (Getting Started)

### پیش‌نیازها
- Node.js >= 18
- ابزار npm یا pnpm
- Android Studio / Android SDK (برای شبیه‌ساز یا دستگاه فیزیکی)

### نصب و اجرای پروژه

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه Expo
npm start

# اجرای مستقیم روی اندروید
npm run android

# بررسی تایپ‌ها
npm run typecheck

# اجرای تست‌های خودکار دامنه
npm test
```
